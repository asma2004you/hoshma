# عامل واکنشی ساده — مسئله کلید نور در محیط ۲×۲

**هدف عامل:** خاموش کردن همه خانه‌های روشن.

---

## ۱) الگوریتم عامل واکنشی ساده (Simple Reactive Agent)

**تعریف:** عامل واکنشی ساده تابعی است از ادراک مستقیم به اکشن، بدون هیچ حافظه یا مدلی از محیط:

```
اکشن = f(ادراک لحظه‌ای)
```

یعنی عامل نه گذشته‌اش را به‌خاطر می‌سپارد، نه وضعیت محیط را حدس می‌زند، نه برنامه‌ریزی می‌کند. فقط یک **جدول شرط–اکشن** (Condition–Action Rules) دارد.

### گام‌های الگوریتم در هر تکرار

1. **ادراک (Perceive):** حس کردن وضعیت فعلی محیط (در اینجا: وضعیت ۴ چراغ + موقعیت خود عامل).
2. **تطبیق قاعده (Match rules):** مقایسه ادراک با مجموعه قواعد `IF شرط THEN اکشن`؛ اولین قاعده‌ای که شرطش برقرار است انتخاب می‌شود.
3. **انتخاب اکشن (Act):** اجرای همان اکشن (حرکت یا فشردن کلید).
4. **تغییر محیط:** محیط وضعیتش را به‌روز می‌کند و عامل به گام ۱ برمی‌گردد.
5. **شرط پایان:** وقتی هیچ قاعده‌ای جز «توقف» برقرار نشد، مأموریت تمام است.

### قواعد پیشنهادی برای این مسئله (اولویت از بالا به پایین)

| # | شرط (ادراک) | اکشن |
|---|---|---|
| ۱ | خانه‌ای که روی آن هستم **روشن** است | `TOGGLE` (کلید را بزن → خاموش شود) |
| ۲ | خانه‌ام خاموش است اما جای دیگری **روشن** است | حرکت به سمت نزدیک‌ترین خانه روشن |
| ۳ | **هیچ** خانه‌ای روشن نیست | `NOOP` (پایان) |

### چرا الگوریتم قطع می‌شود (اجبار پیشرفت)

- هر `TOGGLE` روی خانه روشن، تعداد چراغ‌های روشن را دقیقاً ۱ واحد کاهش می‌دهد (حداکثر ۴ بار).
- هر حرکت به سمت نزدیک‌ترین چراغ روشن، فاصله مانهتن تا نزدیک‌ترین چراغ را دقیقاً ۱ کاهش می‌دهد → پس در چند قدم حتماً روی یک چراغ روشن می‌رسد.
- بنابراین حلقه یا نوسان نامتناهی ممکن نیست و عامل حداکثر حدود ۱۲ قدم طول می‌کشد.

### نکته مهم درباره ادراک

چون عامل حافظه ندارد، ادراکش باید **کامل** باشد (کل شبکه ۲×۲ را ببیند). اگر فقط خانه زیر پایش را حس می‌کرد، برای پوشش همه خانه‌ها به حافظه یا الگوی ثابت نیاز بود و دیگر «واکنشی ساده» خالص نبود.

---

## ۲) ساختار کد (`reactive_light_agent.py`)

- **`LightSwitchEnv`** — محیط ۲×۲ با متدهای `perceive()` (ادراک کامل) و `step(action)` (اعمال اکشن + برخورد `bump` در صورت خروج از شبکه).
- **`SimpleReactiveAgent`** — تابع خالص `decide(percept) -> action` بدون حافظه، مطابق جدول قواعد بالا (نزدیک‌ترین خانه روشن با فاصله مانهتن و اولویت حرکت سطری).
- **`run()`** — حلقه استاندارد عامل–محیط با نمایش گام‌به‌گام.
- **`main()`** — یک اجرای نمونه (همه چراغ‌ها روشن) + ۱۰۰ آزمون تصادفی با `assert` برای اثبات خاموش شدن همه خانه‌ها.

قدم 3: TOGGLE  -> خاموش کردن (0,1)

قدم 5: TOGGLE  -> خاموش کردن (1,1)
